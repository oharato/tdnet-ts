# 要求仕様書 (REQUIREMENTS)

## プロジェクトの目的
東京証券取引所の適時開示情報（TDnet）データを取得し、公開されているPDFドキュメントをMarkdown形式に変換してローカルに蓄積・検索可能にするライブラリおよびCLIツールを開発する。

## 主な要件

### 1. データ取得
- [ヤノシン TDnet API](https://webapi.yanoshin.jp/tdnet/) を利用して適時開示情報の一覧を取得すること。
- 開示情報からPDFのURLを取得し、実際のドキュメントファイルをダウンロードすること。
- APIのレートリミットを厳守し、連続したアクセスには適切なスヌーズ（ディレイ処理）およびリトライ機能を設けること。

### 2. データ変換と保存
- ダウンロードしたPDFからテキスト情報を抽出し、Markdown形式に変換すること（`@opendocsg/pdf2md` を利用想定）。
  - **テキスト最適化**: 変換されたMarkdown内の過剰な見出しや連続する改行を圧縮すること。
- **データの正規化**: 銘柄コードを4桁に正規化（末尾「0」を除去）、URLのリダイレクトパラメータを除去、開示日時をUTC（ISO8601形式）へ変換すること。
- **ドキュメントID**: PDFのURLベースネーム（例: `140120260220565990`）をドキュメントIDとして使用し、主キーとすること。
- **PDF原本の保存**: `--save-pdf` オプションにより、ダウンロードしたPDFファイルを指定ディレクトリにローカル保存できること。ファイル名は `{id}.pdf` の形式とする。
- 取得した開示情報のメタデータ（ドキュメントID、会社コード、会社名、開示日時、件名、URL等）および変換されたMarkdownテキストを SQLite データベースに保存すること。

### 3. データ検索
- 保存された SQLite 内のデータを、指定期間やキーワードなどの条件で検索できる機能を提供すること。

### 4. インターフェースの提供形態
- **ライブラリとしての利用**: 別プロジェクトのソースコードから関数などを import し、プログラマティックにデータを取得・保存・検索できるようにすること。
- **CLIツールとしての利用**: ターミナルからコマンドを実行するだけでデータの取得（バッチ処理）や検索ができるインターフェースを提供すること。

### 5. Webビューアー
- 優待関連の開示情報をブラウザ上で一覧表示するWebビューアーを提供すること。
- Alpine.jsによるリアクティブな検索・フィルタリング機能を備えること。
- ローカルに保存されたPDF (`web/pdfs/{id}.pdf`) を直接参照可能とすること。
- `pnpm run web:export` で優待関連データをJSON出力し、`pnpm run web:dev` で開発サーバーを起動できること。
